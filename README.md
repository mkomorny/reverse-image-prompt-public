# Reverse Image Prompt Reconstructor

> **Tri-Platform Agent Skill** for Claude Desktop / Code, Grok CLI, and Google Antigravity / Gemini.  
> Forensic-grade prompt reconstruction generating dense prompts and dimension breakdowns from images.

---

## Overview

`reverse-image-prompt` provides standardized capabilities across conversational AI platforms:
- Systematic multi-dimensional visual scan (medium, lighting, composition, optics, textures).\n- Dense 200-500 word continuous prompt block ordered from macro concepts to micro details.\n- Structured dimensional breakdown table for targeted prompt customization.\n- Model-specific rendering tags optimized for Midjourney, Flux, SDXL, and DALL-E.\n- Tri-platform NTFS junctions connecting Claude, Grok, and Antigravity.

---

## Tri-Platform Architecture

Zero duplicate code across platforms. Canonical source resides in `.agents`:
- **Canonical Source**: `C:\Users\<you>\.agents\skills\reverse-image-prompt`
- **Claude**: `C:\Users\<you>\.claude\skills\reverse-image-prompt` (NTFS Junction)
- **Grok**: `C:\Users\<you>\.grok\skills\reverse-image-prompt` (NTFS Junction)
- **Antigravity**: `C:\Users\<you>\.gemini\config\skills\reverse-image-prompt` (NTFS Junction)
